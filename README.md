# 启德建材 · 微信销售小系统

给建材市场做的一个「微信里能用」的销售小工具：客户看货 → 留下手机号询价 → 销售后台跟进。
手机浏览器打开就是小程序的样子，不用装 App、不用申请小程序 AppID。

## 一、跑起来

**双击 `run.bat`**，看到「已启动」后用浏览器打开：

```
http://localhost:8080
```

手机和电脑连同一个 WiFi，用电脑的局域网 IP 访问（例如 `http://192.168.1.5:8080`），手机上就是完整的微信风格页面。

> 依赖：JDK 11 以上（我用的 JDK 22）。`lib/` 里已经放好 sqlite-jdbc 和 slf4j，不用另外装数据库。

## 二、功能

| 页面 | 功能 |
|---|---|
| 商品 | 建材商品列表，按分类筛选（瓷砖 / 卫浴 / 地板 / 板材 / 门窗），显示规格、单价、库存 |
| 询价 | 填称呼、手机号、意向商品、备注，提交后进销售后台 |
| 记录 | 销售视角的询价列表，含客户、电话、意向、时间 |
| 数据 | 在售商品数、今日询价数、累计询价数 |

## 三、技术栈

- **后端**：JDK 自带 `com.sun.net.httpserver.HttpServer`（不装 Tomcat、不引 Spring）+ JDBC
- **数据库**：SQLite（`shop.db`，运行自动建表并写入 7 条建材样例）
- **前端**：原生 HTML + CSS + JS，微信绿 `#07c160`，移动端适配，`fetch` 调接口
- **零第三方后端框架**：整个项目只有 1 个 Java 文件 + 1 个 HTML 文件

## 四、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/products` | 商品列表，可加 `?cat=瓷砖` 筛选 |
| POST | `/api/inquiry` | 提交询价（JSON：name / phone / product / remark） |
| GET | `/api/inquiries` | 询价记录（后台） |
| GET | `/api/stats` | 商品数、今日询价、累计询价 |

## 五、目录

```
启德建材-微信销售小系统/
├─ src/Server.java      ← 后端全部代码（路由 + 建表 + 接口）
├─ web/index.html       ← 前端页面（样式 + 交互都在这）
├─ lib/                 ← sqlite-jdbc、slf4j
├─ run.bat
└─ shop.db              ← 运行后自动生成
```

## 六、面试怎么讲（三句话）

1. **需求从哪来**：建材市场老板的痛点是「客户在微信里问价，销售记不住、跟丢单」，所以做了个留资 + 跟进的轻量工具。
2. **为什么这么写**：不用 Spring 是为了零部署——JDK 自带 HttpServer 起一个端口就能跑，老板电脑上双击就能用。
3. **有啥细节**：手机号正则校验、分类动态渲染、询价落库带时间戳、统计接口当天聚合。

## 七、自己动手改（面试官爱问“这行为什么这么写”）

1. 给商品加「品牌」「产地」字段，改表、接口、页面三处；
2. 加一个 `/api/inquiry/status` 把询价标记为「已联系 / 已成交」；
3. 把询价列表导出成 CSV。

改完自己能讲清楚，再写进简历。
